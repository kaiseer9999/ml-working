# Практическая работа №9. Метод опорных векторов

Это самостоятельный учебный пример для варианта B на двумерном `make_moons`. В текущем репозитории нет основного датасета и материалов ПР-7/8, поэтому результаты здесь нельзя выдавать за сравнение на ваших рабочих данных.

## Запуск

Из каталога `OS/pr09`:

```bash
python -m pip install scikit-learn matplotlib numpy pandas
python svm_pr9.py
```

Скрипт использует стратифицированное разбиение 75/25 и `Pipeline(StandardScaler, SVC)`. Масштабирование обучается внутри каждого фолда GridSearchCV (5 folds), поэтому валидационные данные не участвуют в расчёте параметров scaler. Поиск перебирает `C = {0.1, 1, 10, 100}` и `gamma = {0.01, 0.1, 1, 10}` для RBF. Отдельно обучается линейный SVC на тех же обучающих объектах.

В `svm_pr9_output/` будут сохранены таблица `grid_results.csv`, тепловая карта `grid_heatmap.png` и граница решения лучшей модели `decision_boundary.png`. Консольный вывод содержит метрики на отложенной тестовой части и время GridSearchCV и линейного fit. Время зависит от компьютера и числа потоков; GridSearchCV включает все CV-переобучения и потому не сопоставим с одним fit.

## Интерпретация результатов

- Рост `C` сильнее штрафует ошибки на обучающей выборке и допускает более сложную границу; при чрезмерном значении модель может хуже обобщать.
- `gamma` задаёт локальность влияния точки в RBF-ядре. Малое значение даёт более гладкую границу, чрезмерно большое может обволакивать отдельные объекты и переобучаться. Смотрите на разницу `train_accuracy` и `cv_accuracy` в CSV вместе с тепловой картой.
- Для `make_moons` нелинейная граница обычно уместнее линейной, но окончательный вывод делается по отложенным метрикам и времени именно вашего запуска.
- Чтобы закончить сравнение по условию задания, повторите протокол на основном рабочем датасете и добавьте рядом метрики моделей ПР-7 и ПР-8, полученные на том же тестовом разбиении. Их в этом каталоге нет.

Не переносите метрики синтетического `make_moons` на основной датасет: этот пример показывает методику и визуализацию, а не заменяет эксперимент на заданных данных.
