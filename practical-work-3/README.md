# Практическая работа № 3. Пайплайн предобработки данных

## Цель работы

Собрать пайплайн предобработки данных, включающий обработку пропусков, масштабирование числовых признаков и кодирование категориальных признаков, исключая утечку информации из тестовой выборки в обучающую.

## Используемый датасет

**Titanic Dataset**

Датасет содержит информацию о пассажирах «Титаника»: возраст, пол, класс билета, стоимость билета и другие характеристики.

Источник данных: [Titanic Dataset на GitHub](https://github.com/datasciencedojo/datasets/blob/master/titanic.csv)

Файл датасета находится в папке `data/data.csv`.

## Используемые библиотеки

- `pandas` — загрузка и обработка данных.
- `scikit-learn` — построение пайплайна предобработки.
- `SimpleImputer` — заполнение пропущенных значений.
- `StandardScaler` — масштабирование числовых признаков.
- `OneHotEncoder` — кодирование категориальных признаков.
- `ColumnTransformer` — применение разных преобразований к группам признаков.
- `Pipeline` — объединение последовательных этапов предобработки.
- `train_test_split` — разделение данных на обучающую и тестовую выборки.

## Этапы выполнения работы

1. Загружен датасет Titanic.
2. Целевая переменная `Survived` отделена от признаков.
3. Данные разделены на обучающую и тестовую выборки в соотношении 80/20.
4. Числовые и категориальные признаки классифицированы по типу.
5. Для числовых признаков реализовано заполнение пропусков медианой и масштабирование.
6. Для категориальных признаков реализовано заполнение пропусков отдельной категорией «Неизвестно» и кодирование One-Hot.
7. Преобразования объединены с помощью `ColumnTransformer` и `Pipeline`.
8. Пайплайн обучен только на обучающей выборке и применён к тестовой.

## Обоснование стратегий предобработки

### Числовые признаки

Для заполнения пропусков используется медиана (`SimpleImputer(strategy="median")`). Медиана менее чувствительна к экстремальным значениям, чем среднее арифметическое.

Для масштабирования используется `StandardScaler`, который приводит числовые признаки к сопоставимому масштабу.

### Категориальные признаки

Пропущенные значения заменяются отдельной категорией «Неизвестно». Это позволяет сохранить информацию о наличии пропусков, не подменяя их числовым значением.

Для кодирования категорий применяется `OneHotEncoder(handle_unknown="ignore")`. Он преобразует категории в числовые признаки и позволяет обрабатывать категории, которые не встречались при обучении.

## Предотвращение утечки данных

Разделение на обучающую и тестовую выборки выполняется до обучения преобразований.

- На обучающей выборке вызывается `fit_transform()`.
- На тестовой выборке вызывается только `transform()`.

Таким образом, статистики заполнения пропусков, параметры масштабирования и набор категорий определяются только по обучающей выборке.

## Проверка результатов

После предобработки проверяются размеры обучающей и тестовой выборок. Количество признаков после преобразования должно совпадать.

Проверка выполняется с помощью сравнения количества столбцов в `X_train_transformed` и `X_test_transformed`.

## Вывод

В ходе практической работы создан пайплайн предобработки данных с использованием `Pipeline` и `ColumnTransformer`. Реализованы заполнение пропусков, масштабирование числовых признаков и кодирование категориальных признаков.

Обучение преобразований выполняется только на обучающей выборке, что предотвращает утечку статистической информации из тестовой выборки. Полученный пайплайн обеспечивает согласованную предобработку обучающих и тестовых данных.
